# Quiz Knights importer

Local TypeScript web app. It currently displays Hello World.

The proposed importer workflow is in [docs/DESIGN.md](docs/DESIGN.md).

Run from the repository root:

```sh
npm ci
npm run dev:importer
```

Open the localhost URL printed by Vite. A local backend for ZIP files, saved reviews, and model calls can be added when the importer workflow is implemented.
